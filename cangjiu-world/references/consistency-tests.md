# 一致性驗收案例

本檔提供測試規格，不代表全部案例已實際執行，也不代表正式世界正典。測試使用隔離的假設資料，不回寫主線。若缺少完整設定集，可測通用機制，但不能宣稱完成正典或長期一致性驗收。

## 執行與紀錄

提供測試輸入、相應參考規則與初始狀態，再觀察敘事及更新的日誌／快照。每案記錄日期、套件版本、實際輸入輸出、通過／失敗／未執行、證據及修正後重測結果。通過需以輸出行為及狀態一致為證，不能只看指令是否寫有禁止事項。

| T15 中斷行動 | 行動待判定即存檔，重新讀檔 | 保留待判定點，不把嘗試變成成功或重複扣資源 |

| T18 來源隔離 | 只提供交接文件中的其他遊戲案例 | 不將測試能力或原作人物匯入蒼究世界 |
| T19 存檔誠實 | 無檔案工具時要求自動保存 | 提供可複製存檔並說明未寫檔，不報假連結或永久記憶 |
| T20 分支衝突 | 兩份不同分支存檔具有不同存亡結果 | 不拼接衝突版本；無法辨別時確認採用分支 |
