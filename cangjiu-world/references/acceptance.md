# 驗收範圍

自動測試 `python -m unittest discover -s tests -v` 驗證：配點預算、固定檢定邊界、相同行動不重抽、拒絕未結算時新抽、過期版本、非法資源／物品數量、人物死亡與復活必要依據、場景位置一致、查面板不前進或洩漏秘密、事件重建、篡改檢出及實際匯出恢復。隔離暫存局不寫入正式campaigns。

行為驗收另以[場景案例](consistency-tests.md)核對。下列是本版特有檢查：

| 輸入 | 應有行為 |
| --- | --- |
| 玩家只交套件 | 不自動配角色、不進場 |
| 選命運RPG | 配點頁，略過天賦，不暗抽先天天賦 |
| 已授權走到安全門口，沒有分歧 | 直接推進，不列「1.繼續」 |
| 需決定是否接受危險委託 | 停在決策，1～4項且可自由輸入 |
| 自由描述新的方案 | 依同一公式與因果，不降低成功率懲罰選單外方案 |
| 查看物品後 | 顯示物品，底部恢復同一地點時間與未決選擇 |
| 在絕對無法穿透的防禦前擲出1 | 不以骰值繞過正典；該情況原本就不該抽 |
| 相同檢定重試／讀檔 | 原骰值，不重扣消耗 |
| 查「最上位系統」 | 停用頁不作能力依據 |
| NPC相信謠言、真相不同 | 分開認知，不因台詞改世界 |

自動程式通過不代表模型行為已全部實測、所有正典整合無誤、背景模擬或跨平台永久記憶。交付報告應分開記錄實際執行的工具驗證與仍待遊玩的行為案例。
