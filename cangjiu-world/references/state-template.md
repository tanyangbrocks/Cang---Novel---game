# 無工具環境的續玩模板

保存以下實際資料，不適用標不適用，未知標未確認；玩家可見與主持秘密分開。

- schema_version / rules_version：2.0。
- save_id / parent_save_id / branch_id / 最後事件ID。
- 遊玩模式story/rpg，創角或playing階段，創角方案與配點。
- 正典版本指紋、作者裁定版本、停用來源ID。
- 世界時間及精確程度、地點、現場情況、有效選單。
- 玩家最後行動、已判定與未判定部分、底部劇情錨點。
- 玩家身分背景、能力來源與定義、限制例外、體系資源與標定基準。
- RPG八屬性、HP及傷勢、防禦通道、技能與物品所有者／數量、資產負債。
- NPC位置、存亡、動機、能力、各自所知與獲悉途徑。
- 關係的客觀事實與玩家可見資訊分開，未知內心不填成確定。
- 事件序列、來源、前後變化，尤其死亡、能力取得、移動、承諾。
- 未結期限與場外進展、暫定新增、衝突及已更正錯誤。
- 檢定ID、固定參數、骰值與結果、是否已結算；沒有骰值寫待判定。
- 最後持久化範圍與尚未保存資料。

從最後決策點接續，不重置傷勢與後果。結構化JSON存檔已有這些資料時不另建一份互相矛盾的主資料；文字摘要用於閱讀，不宣稱能無損還原遺失日誌。
