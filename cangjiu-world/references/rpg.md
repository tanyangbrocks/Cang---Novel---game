# 沉浸式命運RPG｜玩法規則2.0

下列是作者授權設計的遊戲尺度，與正典分層。若機械數據與明文能力／法則例外相衝，以正典為準，記錄例外依據，不用抽骰削弱。

## 開局配點（天賦暫不設計）

先選模式，再提供創角配點頁，不先進行玩家未同意的劇情。預設可選人族普通起點；種族、姓名、年齡、身分、地點可自訂，但強大種族與境界不能由低價技能點自動購得。非人族須先依正典建立身體與能力基準，另記 `creation_profile`；內建數值工具v2僅自動支援普通人族，其他起點可採手動角色卡且使用相同檢定公式。

- 八項基礎屬性：顏值、智力、體質、力量、敏捷、感知、意志、魅力。各從5起，40點自由分配；每加1花1點，開局上限15，最終總和80。普通成年未超凡人族的參考平均為10；外貌是該社會參考觀感，不宣稱跨種族客觀審美。
- 技能另有6點，1點升一級，單項最多3級，必須分完。普通技能目錄：觀察、交涉、潛行、野外求生、閱讀演算、急救、武器基礎、工藝。可自訂同等範圍的普通技能，固定名稱與ID後記錄。武器基礎只代表受訓，不自動授予武之領悟、神兵、真氣或魔法。
- 運氣初始10作RPG中性值，未設計可配天賦；命運的正典分類仍另列，不能從10推定任何命格。悟性也不等同智力。
- 財富不從屬性池購買，普通人族預設開局現金1000星盟幣，基本衣物、背包、7日普通口糧、水壺；這是遊戲開局方案，不是世界平均收入。消耗按實際事件記錄。特殊背景若改變資產須先顯示並保存。
- 預設不具能量操控，不自動抽中靈玉或魔法天賦；角色可選有正典依據的力量起點，另核對資格與初始能力卡，不以技能點當先天天賦。
- 顯示配點預覽，可任意重配；玩家確認前不進場或生成經歷。提供可修改的均衡建議：八項皆10，觀察2、交涉2、野外求生2。

## 數值尺度與衍生欄位

可成長屬性不受15終身上限；10為參考基準，20代表該可量化維度約2倍，40約4倍。超凡能力不必全轉成肉身屬性；法則、心境、技術與血脈效果另存，不把星盟階級硬換為HP或屬性。

普通人族初始HP上限＝體質×10；基礎物理防禦＝體質÷2。防禦是該通道可抵消的普通傷害參考值，不等於任意攻擊免疫。無裝備普通有效接觸攻擊輸出＝力量×2，須先能觸及對手。普通命中傷害＝max(1, 輸出－該通道有效防禦)，四捨五入；明確免疫為0、無法命中不扣HP。魔法、毒、魂與法則攻擊不能拿肉身防禦統一相減。技能命中與傷害各判一次機制，不重複擲同一件事。

傷勢另記部位與功能；要害、斷肢、魂消亡等以正典具體因果處理，不因尚有HP而免死。HP0是失去維持正常行動能力、需判定瀕死／死亡的門檻，不自動當魂消滅。無依據不新增死亡豁免骰、每日回滿或復活。

每種可操作能量使用獨立資源ID。MP是該體系儲量顯示值，不可跨體系互換；1MP＝該角色該體系一個已登記「基礎操作單位」的消耗，能量卡須固定基準與來源。未建立基準時顯示未標定，不臆測MP或施法消耗。取得新體系時按角色卡標定基礎操作、池量、輸出與技能成本；不能以遊戲MP替正典無消耗能力新增代價。

普通RPG新增技能若需數值成本：只在其機制原有資源消耗且基礎操作已標定時，以1／2／4／8個基準單位標記低／中／高／極高消耗，首次建立卡時固定；無正典數據則明標為本局新增的量化方式。已有精確原文消耗或例外優先，修改另記版本。恢復依休息、修煉或物品機制，不自動每回合回復。

魔法詳情分開瑪納儲量、魔力輸出、功率、適應性與抗性。奎因是正典破壞力單位，未標定就顯示未測定，不把1MP等同1奎因；龐頓與奎因不可換算。

## 固定檢定

先過資格關：能力能否做到、是否可接觸、是否有工具／資訊、是否被絕對規則阻斷。確定成功／失敗直接判定，不抽骰。真正可成可敗且有後果才抽D100。非必要的普通動作不抽。

固定參數：主屬性A、所需能力D、使用者技能r、所需技能q、情境c與運氣L。A、D須大於0；同一種障礙有固定ID及D、q，除非障礙本身改變不得因玩家強大而調高。

`成功率p = clamp(5,95, round_half_up(50 + 20×log2(A/D) + 5×(r-q) + c + clamp(-5,5,(L-10)/2)))`

- 每次一項主屬性，必要時可用兩項幾何平均，必須在擲骰前固定。技能0～3是初始受訓級別，可在有訓練事件後成長；技能點不等於超凡境界。
- 普通人族障礙D參考：5容易、10一般、15困難、20極難、40遠超常人；q為所需技能級。工具能完全滿足需求就直接成立，不強行抽骰。
- c以一個整體情境評估固定為-20／-10／0／10／20，不疊加同一優勢。明顯準備或有利地形+10、決定性但非必勝優勢+20；不利反向。傷勢影響也納入c，不再重複扣同一條件。
- 擲1～100，骰值≤p成功。成功且p－骰值≥30為出色；失敗且骰值－p≥30為明顯失敗。程度只影響原行動範圍內效果，不憑空斷肢、暴擊致死、學會法則或引發無關災難。無一般強制大成功／大失敗。
- 反制者以對應防禦屬性作D、技能作q，同一動作只抽一次；先手依場景先機與敏捷，不每回合重抽全套。互相攻擊屬不同動作，各依當時狀態判定。
- 判定輸出可簡寫「觀察 65%｜D100=42｜成功」；秘密檢定不向玩家洩露敵方數據，但主持存檔須保存參數與結果。
- 實際工具抽樣或玩家擲骰；沒有兩者就標「待擲骰」，不能聲稱真的抽過。一次行動使用穩定check_id，讀檔與重試取原值；改變方案需新行動，不可無代價重複嘗試同一既定結果。

## 成長與社會數值

不因每次點選直接加點。一次有實質風險或新學習的目標完成後記進展，同一目標不可重複刷。累積3個不同已記錄進展，可獲1成長點；加一項普通屬性1，或普通技能1級（最多5級）。須有相應訓練／經歷依據；不能買靈玉、命格、境界、神格或正典能力。正典修煉突破依原條件處理，與成長點分開。跨境界的屬性變化若無原始倍率只可記為本局量化新增，不自稱官方值。

好感-100～100、信任0～100、戒心0～100，初識通常0／0／50。每個有關事件一般變動1～5、重大5～15、極重大15～30，須記理由，不按玩家選項固定加分。未知真實數字對玩家顯示「未知／推測區間」，不得全知揭露；角色有正典讀心能力也須按範圍判定。

地區／勢力評價-100～100，不同群體分開，名望不等於好感。複合能量「聲望」及特殊價值「望」是另兩筆資料。財富列現金、存款、資產、負債，不把未知資產估成現金。


RPG自由時間、AP、活動耗時、特殊情境及跨月處理遵循[時間與行動點](rpg-time.md)。故事模式不套用AP。RPG總覽另顯示年齡、月內時間、AP上限／剩餘、當前活動與情境。
