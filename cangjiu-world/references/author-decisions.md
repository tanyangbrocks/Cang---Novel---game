# 作者核定裁定

本檔裁定優先於未修訂的原稿；對外版已套用主要修正。未定義不自動補成無限或禁止。

| 問題 | 作者核定內容 | 狀態與適用邊界 |
| --- | --- | --- |
| 1 | 以「有靈玉者不到百分之一能修煉」為準；作者以整體萬分之一概括。 | 已定主要敘述。若有靈玉者約百分之一，嚴格換算為整體不到萬分之一；「萬分之一」作概略值，不擅改成精確抽樣機率。 |
| 2 | 靈玉璀璨度採線性倍率；金15為金1的十五倍。 | 已定。以同屬性璀璨1為基準，璀璨n為其n倍；不額外推定零璀璨或其他屬性的跨屬換算。 |
| 3 | 生靈積累記憶時，記憶同時記錄於腦或其他承載位置，以及魂中。常規手段可以改寫腦內記憶，但不能改寫魂中記憶。腦內記憶遭竄改時，腦通常只能讀到已遭竄改的腦內記憶，正常情況讀不到魂中記憶。 | 已定記憶機制補充。不能因魂中仍有原始記憶就讓角色自動識破、免疫或恢復被改寫的記憶。特殊讀取魂中記憶的方法尚未因此被定義；亦不推論已解決魂全部其他資訊與結構的問題。 |
| 4 | 「掌控」不等於「操控」：生靈可透過工具或方式操控價值，與直接掌控價值不同，如人類利用工具操控電與雷神直接掌控電之差別。 | 已定用語區分。至尊詭道的操縱不直接等於推翻「不能直接掌控價值」；不據此創造新的價值工具或方法。 |
| 5 | 神聖力與精神力可以混合、累積複合能量「聲望」；「聲望」可強化特殊價值「望」。 | 已定。兩個不同項目分別保存，不再將「聲望」與「望」合併；不虛構強化倍率、效率或上限。原文否定混合來源的敘述應依此修正理解。 |
| 6 | 法則分類以「法則」專篇為準。 | 已定。道極篇不一致的分類不再作為競爭版本；不變更其餘無衝突內容。 |
| 7 | No.1～108屬通用魔法，No.109起為環魔法；忽略環基礎區的No.101條目；強行取得對方魔法控制權的No.80改為No.180。 | 已定。原本瞬發空間轉移的No.80保留；最後24種雙重魔法等未被本次變更的分類仍按原文。 |
| 8 | 224種標準直擊魔法在世界中存在，但部分作者尚未寫出。 | 已定。缺少的名稱、術式與效果仍未提供，不由系統自動補齊為正典。 |
| 9 | 拉普拉斯九環九漩是其獨有例外。 | 已定。不推廣為一般種族的正常成長路線。 |
| 10 | 瑞神龍不能使用魔法，龍蛋段落的魔力敘述是筆誤；翼神龍也有龍爪技，其段落出現「瑞神龍」為複製殘留。 | 已定。瑞神龍龍蛋不使用魔力；翼神龍段落的龍爪技主體應為翼神龍。其餘能力數值維持原文。 |
| 11 | 伴生配對以詳細設定為準；龍與鳳不是伴生，概述為舊資料。 | 已定。翼神龍與瑞神龍互制，鳳與天球互制。 |
| 12 | 次元物種為六族。 | 已定。影族、幻想蟲族、機械族、元素靈族、幻形族、深淵族。 |
| 13 | 常見S鬼域「極黏唾液」由12%改為22%。 | S鬼域合計問題已解決：常見類型合計90%，其餘稀有10%，合計100%。原問題另提的基因強化機率未獲裁定，不連帶調整。 |
| 14 | 六龍聖天帝國名稱以其專頁為準。 | 已定。正式全稱為「若夢埃頌元境紫雲宸聖天帝國」，簡稱「六龍聖天帝國」。專頁所列六大貴族為若、夢、埃、頌、元、境；舊稱殘留不另外建立國家或家族。 |
| 15 | 相關草稿直接忽略；拉普拉斯亦屬例外。 | 已定。此處草稿指原問題援引的「真尋者草稿設定」中真正永生等敘述，不據此全面刪除其他無關草稿；不將草稿的永生宣稱納入正式判定。拉普拉斯保留為原問題中留凡間情況的例外，不擴張為所有神界限制的豁免。 |
| 16 | 只有少數很強的高階鬼族能持續獵食；嚴密防禦、秘密維安及極低非自然死亡率是相對外界而言，實際能持續獵食的鬼族很少。 | 已定。不得將相關低階鬼族專篇的絕對化描述解讀成普遍、無代價、無法防禦的持續獵食；個別種族如何對應仍以作者明示條件為界。 |
| 17 | 天官鬼老的禁食只限制新捕食，不涵蓋既有行為。 | 已定。原有隱藏事實與禁令可以並存；不將公開禁食形象等同已釋放所有既有受害者。 |
| 18 | 神壇表與星龍鳳神所指的戰神是同一位；「十大主神教派」改稱「十大神明教派」。 | 已定。不因教派總稱推定其信仰對象皆具有上位主神神格。 |
| 19 | 大地域採原版，不採地球起源構想；問題19所述其他設定亦不採用。 | 已定。本項「其他設定」依問題19的範圍理解為其他草稿構想、他作參考及GPT命名候選，不推廣為刪除整份設定集其他正文。大地域既有地理、社會與對外關係保留，地球起源備選不啟用；已在正式專篇使用的神名不因命名候選停用而消失。 |
| 20 | 統一為「剎業判官」「夢幻族」「反物理」；水行篇寫肢節體系、靈獸篇寫魔獸均為筆誤。 | 上述已定，分別按水行體系與靈獸理解。作者後續核定：「靈根」統一為「靈玉」，「五意花」統一為「五神花」。 |
