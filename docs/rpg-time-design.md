# 命運RPG：自由時間與特殊情境

作者新增的RPG流程需求。這是同一遊玩模式內的兩種進行狀態，不是另外兩個開局模式；故事冒險模式不被強制套用月制或行動點。

## 自由時間

- 類人體系每一個時間單位為一個月，配合世界曆法以30天作一個月；12個月對應一恆。以角色年齡顯示長期時間，如「18歲3個月」，另外保留月內日與實際耗時，不能每則訊息都增加一個月。
- 玩家花行動點安排修煉、學習、工作、交際、探索、休息等行動，也可自行描述。每單位可用行動點依當前狀態而定。
- 行動卡分開列「行動點成本」「預計實際耗時」「條件」「可能收益／風險」。行動點代表本單位的活動安排額度，不是所有能量共用的MP，也不表示固定一天或固定時數。
- 行動可累積屬性、技能、財富、關係或其他進展，也可有代價、負面結果或特殊事件；依行動內容、角色狀態與統一檢定處理，不保證每次加點。
- 每次結算先檢查行動點與月內時間，兩者皆可行才開始。不能只靠行動點多就把超過一個月的互斥行程塞進同月。
- 月結時依實際時間處理年齡、傷勢、持續效果、資源、工作義務與場外事件；沒有既定依據不新增固定稅款、生活費或強迫災難。不在玩家仍有待決定行動時擅自跳月。
- 行動點耗盡不代表角色失去說話、避險或應對危機的能力；不能把介面額度當作正典生理限制。不能再安排無依據的額外成長活動，但仍可處理當前事件或選擇休息／結束本單位。

## 特殊情境

- 主角捲入戰鬥、對話、祕境等需要持續應對的情境時，切換為特殊情境；依玩家選擇與自由行動持續處理，直到事件解決、退出或因其他合理原因結束。
- 戰鬥、對話與祕境的推進尺度按現場實際耗時處理，不因每次選擇就經過一整月，也不固定每輪耗時相同。
- 有實際決策時給1～4個具體選項，第一項為常規方案，玩家可自由輸入；沒有決策就正常推進，不反覆要求選「繼續」。
- 特殊情境不逐句扣月行動點；其實際時間、MP、道具與傷勢依事件結算。若活動本身原有月行動點成本，保存已扣與待結算紀錄，不能因切換重複扣同一筆。
- 進入時保存自由時間的位置、月內進度、剩餘行動點、被中斷活動與已完成進展；結束後回到事件發展後的實際位置與時刻，而不是無條件傳回進入前地點。
- 若事件跨月，依真實時間逐月結算，不凍結年齡、不累積無上限行動點，也不讓過期機會持續存在。
- 祕境內的戰鬥或對話屬情境內子事件；子事件結束不代表整座祕境已結束。需保存上層情境，避免過早退回自由時間。

## 查詢、畫面與保存

面板加列「進行狀態：自由時間／特殊情境」。自由時間另列角色年齡、本月進度、可用行動點；特殊情境列事件名稱與當下階段。查詢不消耗行動點或時間；回覆底部始終恢復目前劇情錨點與有效選單。

存檔需保留：進行狀態、角色時間基準與年齡、時間單位長度、月內已過時間、行動點上限／剩餘／調整依據、當前活動與已扣成本、事件階段、上層情境及恢復位置。這些是後續工具欄位需求，既有2.0資料工具尚未自動管理行動點或跨月結算；不得宣稱已實作。

其他種族的時間單位尚未由本次需求定義，不自行按壽命比例縮放。行動點基準量、狀態調整公式與各活動成本尚待數值設計；不要把示意數字當作已上線的固定值。公開版2.1是此前交付，不因本文件更新便宣稱已重新打包。
